    Install a script

    A script can read and change the sites it runs on. Install only scripts you trust.

    Link bypass

    When this is on, a link BM Osprey cannot resolve is sent to bypass.vip, an outside service, through your network route. It needs your own API key and stays off without one. The key is kept as plain text in BM Osprey's settings file. It is never used in private mode. Without a key, Open in bypass.vip puts the link in their page, and nothing is sent until you press their button.

    Browser extensions

      Extensions load the next time BM Osprey starts, and never in private tabs.

      Privacy

      Private tabs keep nothing after they close. WebRTC, which can leak your real address, is off in private tabs and in every tab while WARP, a VPN or Tor is on. Whatever the route, it fails closed: if it is down, nothing is sent. Downloads always leave through the same route as your tabs.
